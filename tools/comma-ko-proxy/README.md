# COMMA 한국어 대전 (비공식 실험 버전)

원본: https://can-you-defeat-comma.pages.dev/

원본 COMMA 사이트의 HTML과 자산을 요청 시 중계하고 표시되는 일본어 UI·포켓몬·기술·도구·특성·성격 명칭을 한국어로 치환하는 실험용 게이트웨이입니다. 원본 제작자와 무관하며 공식 서비스가 아닙니다. 원본의 게임 엔진과 학습 모델은 포함하거나 수정하지 않습니다.

일본어·한국어 고유명사는 PokeAPI의 다국어 CSV 파일에서 읽어옵니다. 포챔스 신규 폼이나 용어는 수동 목록으로 보충합니다. 텍스트만 바꾸므로 이미지 내부 글자는 번역되지 않습니다. 대전 기능, COMMA의 서버 API, WebSocket 등은 원본의 정책과 구조에 따라 정상 동작하지 않을 수 있습니다.

운영 시 원본 제작자의 콘텐츠 사용 조건을 확인하고 요청이 있으면 서비스 중계를 중지해야 합니다. 개인 비밀번호 등 민감 정보를 입력하지 마세요.

Node.js 20 이상에서 `node tools/comma-ko-proxy/server.mjs` 으로 실행하며 `PORT` 환경변수 지정이 가능합니다. 의존 패키지는 없습니다.
