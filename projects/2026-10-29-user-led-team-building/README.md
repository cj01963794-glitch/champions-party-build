# 사용자 주도 포켓몬 챔피언즈 파티 구축 — 자료 수집 프로젝트

> 시작일: 2026-10-29 (KST)
> 상태: 진행 중
> 상위 저장소: `champions-party-build`
> 구분: 이전 AI 주도 시험 구축(A·B·C)과 별도 프로젝트

## 목적과 역할

- **사용자:** 파티를 직접 구상·설계·평가하고 최종 판단한다.
- **어시스턴트:** 사용자가 요청한 데이터·근거를 충분히 수집하고 출처를 명시하며, 검증 가능한 범위와 불확실성을 구분한다.
- 사용자가 별도로 요청하지 않는 한 어시스턴트는 포켓몬 추천, 기술배치 변경, 파티 초안 제시, 독자적인 구축 방향 설정을 하지 않는다.
- 기존 시험 구축 **A·B·C는 전부 폐기**했다. 신규 작업의 출발점이나 기본 파티로 사용하지 않는다.
- [구축 철학 v1.1](../../docs/TEAM_BUILDING_PHILOSOPHY.md) 및 과거 실패 기록은 배경 참고·자료 해석/검증에 한하여 활용한다. 사용자가 새 운영 방식을 제시하면 그 방식이 우선한다.

## 자료 수집 및 기록 원칙

1. 사용자가 필요한 데이터와 조사 범위를 지정한다.
2. 사실·직접 확인한 원자료·사용자 제공 정보·추정·미확인을 명확히 구분한다.
3. 데이터별 출처, 확인 시점, 조건(해당하는 시즌/레귤레이션/배치/상황)을 기록한다.
4. 수집된 자료를 사용자의 구축 판단으로 자동 변환하거나, 과거 파티의 검증 결과로 오용하지 않는다.
5. 새 프로젝트의 대화 및 조사 결과는 **이 폴더에 별도 기록**한다. 파일 기록이 필요할 때마다 실제 GitHub 쓰기 작업을 수행하고 성공을 확인한다. **대화가 자동·실시간으로 GitHub에 백업되는 기능은 없다.**
6. 사용자가 승인한 결정과 어시스턴트의 제안·가설을 구분한다. 사용자의 요청 없이 기존 철학 문서나 과거 실패 기록을 수정하지 않는다.
