# 고속 선봉 위협군 7종의 대표 배치 — 허점 검토 (2026-10-29)

> 출처: 사용자가 직접 제안한 7종의 배치 가정 및 2026-10-28~29에 열람 가능한 포켓몬 챔피언즈 M-7 싱글배틀 자료.
> 성격: **배치 가정의 누락과 포푸니크 선봉의 반례를 구분한 분석**. 사용자의 기술배치를 확정적 실제 정답으로 취급하지 않음.
> 이전 자료: [노말주얼 포푸니크 대면 검토](SNEASLER_NORMAL_GEM_LEAD_REVIEW_2026-10-29.md).

## 사용자가 제안한 일곱 배치 (원문 아래 세션 로그 보존)

- 메가루카리오Z: 특수, 철제광선 / 기합구슬 / 악의파동 / 진공파
- 메가라이츄Y: 특수, 속이기 / 전자포 / 기합구슬 / 풀묶기
- 개굴닌자: 특수 기합의띠, 냉동빔 / 오물웨이브 / 악의파동 / 물수리검
- 마스카나: 물리 구애스카프 또는 기합의띠, 트릭플라워 / 트리플악셀 / 번개펀치 / 기습(탁쳐서떨구기)
- 포푸니크: 물리 노말주얼, 속이기 / 인파이트 / 독찌르기 / 섀도클로
- 에이스번: 물리 구애스카프 또는 기합의띠, 화염볼 / 무릎차기 / 더스트슈트 / 기습
- 메가메타그로스: 물리, 사이코팽 / 불릿펀치 / 지진 / 냉동펀치(번개펀치)

## 발견한 누락과 중요도

### 1. 배치 별 스피드 투자량이 누락됨 — 매우 중요

노말주얼 곡예 포푸니크가 **고집 S0**이면 실수치 140 → 곡예 후 280.
- 최속 구애스카프 에이스번 282, 최속 구애스카프 마스카나 288보다 느림.
- **고집 S5**면 (120+20+5)×2=290으로 둘 모두 추월. S4는 288로 최속 스카프 마스카나와 동속.
- 하지만 SP 투자 전환은 B/HP 등에서 비용이 발생하며 +1/+3 선공기의 우선도는 못 넘음.
- 메가라이츄Y의 속이기와 포푸니크 미러는 우선도 +3이 같으므로 성격·SP를 반영한 실제 스피드 비교가 필요. 메가라이츄Y 종족값 130 vs 포푸니크 120만으로 모든 배치의 선공을 단정하지 않음.

### 2. 마스카나·에이스번의 스카프형과 기띠형을 분리해야 함 — 매우 중요

- 마스카나 스카프형은 **유턴**, 탁쳐서떨구기를 포함한 배치가 실제로 널리 사용. 사용자 표의 번개펀치·기습 조합만 보면 상대가 **공격하지 않고 고스트/쿠션으로 빠져나가며 유리한 대면을 넘기는 수순**이 사라진다.
- 스카프형은 기술이 고정되므로 기습을 선택하면 상대가 변화기/교체로 활용할 수 있는 약점이 생김. 기띠형의 기술과 하나의 네 칸 배치로 묶으면 서로 다른 리스크를 흐릴 수 있음.
- 에이스번 스카프형도 유턴이 자주 채용되고 기띠형에는 기습이 흔하다. 도구 선택에 따른 4기술의 결합을 따로 확인해야 함.

### 3. 메가루카리오Z의 나쁜음모/파동탄·러스터캐논이 누락됨 — 중요

- 특수형 자체는 맞지만 기술 4칸을 철제광선/기합구슬/악의파동/진공파로 완전히 고정하면, 실제 채용률이 높은 **나쁜음모, 파동탄, 러스터캐논**이 빠짐.
- 나쁜음모를 허용하면 선봉이 상대 교체를 강요할 때의 기점 가치가 크게 달라진다. 메가 전에 **정신력**인 루카리오는 속이기를 맞고도 풀죽지 않는 수순을 택할 수 있다.
- 메가 후 **파동의방호**는 '선공기 반감'이 아닌 **접촉기 피해 반감**이다. 포푸니크 인파이트 등도 해당.

### 4. 노말주얼 포푸니크의 독찌르기 vs 페이탈클로 — 중요

- 포푸니크의 전용기 **페이탈클로**가 M-7 싱글 약 95~96% 채용되는 반면, 사용자가 제시한 것은 **독찌르기**이다.
- 둘 다 독 물리 위력 80 / 명중 100이지만 챔피언즈에서 페이탈클로는 **30% 확률로 독/마비/잠듦 중 하나**(각 약 10%)를 부여. 독찌르기는 **30% 확률로 독**만 부여. 따라서 한쪽이 모든 경우에 무조건 상위 호환인 것은 아니나, 페이탈클로의 마비/수면 압박을 빼고 포푸니크를 평가하면 쿠션이나 기점 잠재력을 과소평가할 수 있음.
- 기술이 본인 의도에 따른 고정 배치면 수정 필수는 아니나, '현재 대표적인 형태'로 적을 때는 페이탈클로를 우선 확인해야 함.

### 5. 개굴닌자는 기합의띠 이외 메가폼·스카프도 존재 — 범위의 한계

- 사용자가 **기합의띠 개굴닌자**를 시험 대상으로 지정하는 것은 적법하며 대면 계산도 가능.
- 그러나 10/28 근처 사용 통계에서 개굴닌자나이트 약 45%, 기합의띠 약 33%, 구애스카프 약 9%. 따라서 이 한 세트만으로 '개굴닌자 전체'를 대표한다고 보면 누락된다.
- 기술 배치에서 강한 물 타입 공격이 **물수리검 하나**라 교체 대상으로 대한 즉각적인 압박은 다른 파도타기/하이드로펌프형보다 낮을 수 있음. 특성(변환자재/급류)과 SP도 구분해야 함.

### 6. 포푸니크와 일곱 대상 간 기술 타점 자체의 재점검

- **마스카나 풀/악**: **격투 2배, 독 2배**가 정확하다. 이전 문서의 '풀 타입이 격투를 반감하므로 인파이트 1배'라는 판정은 오류였고 2026-10-29 정정함. 공격·스피드 투자형을 상대로 노말주얼 속이기→인파이트가 처치 가능한 수순임을 [추가 검증 문서](THREE_SASH_SCARF_LEADS_STABLE_ANSWER_2026-10-29.md)에서 계산했다.
- **메가루카리오Z 격투/강철**: 인파이트는 강철에 2배이나 파동의방호 접촉기 피해 1/2로 **합성 배율 1배**(격투 자속은 별도)다. 일반 공격형을 처치할 수 있어도 내구 투자형/메가 지연 수순을 고려해야 함.
- **메가메타그로스 강철/에스퍼**: 인파이트는 강철 약점×에스퍼 반감 = **1배**, 섀도클로는 에스퍼 약점×강철 중립 = **2배**. 다만 고물리내구와 우선도+1 불릿펀치 때문에 섀도클로 보유 = 유리 대면은 아님.
- **상대 포푸니크 미러**: 속이기 우선도가 같아 스피드 차이가 핵심이며, 독 공격과 격투 공격은 상대의 독/격투 타입에 각각 반감된다.
- **메가라이츄Y**: 속이기가 먼저 성공하면 포푸니크 쪽 노말주얼의 속이기 소비가 봉쇄될 수 있다. 메가라이츄Y의 **노가드** 아래 전자포·기합구슬은 명중 불안을 피하며 전자포는 마비를 유발. 상대가 스피드 배분이 작은 유형이라면 포푸니크가 먼저 속이기 할 가능성도 있으므로 실제 실수치 확인 필수.
- 포푸니크 속이기의 정상 발동은 **고스트 후출** 또는 **사이코필드에서 접지된 상대** 등으로 막힐 수 있다. 노말주얼이 발동하지 않으면 곡예의 스피드 상승도 적용되지 않는다. 단 이 마지막 두 경우는 사용자가 적은 7종 고정 대면 외의 *팀 단위* 반례다.

### 7. 현재 사용자 7종 기술 구성의 정확한 평가

- **메가메타그로스**: 불릿펀치/사이코팽/지진/냉동펀치·번개펀치라는 기술 구성은 10/27 싱글 사용 통계와 상당히 잘 맞는다.
- **메가라이츄Y**: 전자포/기합구슬/풀묶기/속이기는 싱글에서 충분히 그럴듯하지만, 반드시 이 4개로 고정되는 것은 아니다. **더블**에서의 방어 채용률을 싱글로 혼동하지 않는다(싱글 방어 약 3.3%).
- **메가루카리오Z**: 특수 방향은 맞지만 나쁜음모를 제외한 4공격만 보면 교체 기점으로 생기는 압박을 누락.
- **개굴닌자**: 해당 기띠 배치는 유효한 한 가지 경우지만 모든 개굴닌자를 대표하지 않음.

## 요약

현재 일곱 종을 **고정 4기술의 7개 가상 상대**로 보는 것은 괜찮다. 하지만 **실제 환경의 7종을 포괄하는 모델**로 보려면 특히 '스카프/기띠의 다른 4기술 조합', '속이기 + 곡예의 정확한 스피드', '루카리오 기점기', '포푸니크 페이탈클로'를 구분해야 한다.
