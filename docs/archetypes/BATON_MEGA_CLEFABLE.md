# 필수 전개파티 04 — 그래스시드·명상/철벽 바톤·메가픽시 및 단독 랭크업 (M6)

## 1. 사용자 제공 아키타입과 M6 관측

### 대표 골자

1. 올리르바가 그래스필드를 형성.
2. 클레스퍼트라가 **그래스시드**를 소비해 방어 랭크를 확보.
3. 클레스퍼트라가 **가속**·**명상**으로 능력치를 축적하고 바톤터치로 후속에게 전달.
4. **메가픽시**가 계승한 랭크를 바탕으로 코스믹파워 등을 더 사용하고 스윕.

**중요:** 이 세 마리와 역할은 *대표적인 형태*다. 무조건 동일한 3마리여야 하는 것은 아님.

### 사용자 제시 변형

- 올리르바가 없는 **클레스퍼트라 + 메가픽시**.
- 클레스퍼트라의 명상·가속 바톤을 **지구력 브리두라스**가 수령.
- 클레스퍼트라 대신 **펜드라의 철벽·가속 바톤**.
- 바톤 없이 **메가픽시 단독 코스믹파워** 전개.
- **오롱털 벽 + 하양허브 껍질깨기 바톤**을 여러 수혜자에 연결하는 조합.
- 일반 대면/사이클 코어와 결합하거나, **에써르·포푸니크·거북왕** 사이코필드 전개와 혼합.
- 위 형태는 전부 비포괄적 **예시**이며 상대 6마리/기술배치의 범위를 닫지 않는다.

### 순위 관측 (사용자 제공, 별도 확인한 랭킹 데이터 아님)

| M6 순위 | 사용자 제공 파티 설명 | 우리가 구분할 역할 |
|---|---|---|
| 203위 | 오롱털 벽 + 하양허브 껍질깨기 바톤 + 메가픽시·브리두라스·메가보만다 등 | 벽 지원, 바톤 수혜자 선택의 다변화 |
| 223위 | 하마돈 + 메가픽시 | 바톤이 전제되지 않는 자체 코스믹파워 전개 가능 |
| 895위, 967위 | 펜드라 바톤 + 메가픽시 | 철벽/스피드 중심 전개 |
| 921위 | 클레스퍼트라 바톤 + 메가픽시, 에써르·포푸니크·거북왕과 결합 | 서로 다른 두 전개 코어의 6→3 선택 |

- 사용자 평가: 상위권 300위 안에는 정형적인 형태가 거의 없지만, 대책이 없으면 **도저히 뚫을 수 없게 되기 쉬운 '교통사고 파티'**.
- 이 사례들을 근거로 M6 전체 채용률을 단정하거나, 특정 배치가 가장 흔하다고 확정해서는 안 됨.

## 2. 세 마리 대표형의 세부 기믹

### 2.1. 올리르바

- 특성 **넘치는씨(Seed Sower)**는 *등장 시 자동 발동이 아니라 공격 기술의 피해를 받으면* 그래스필드를 전개한다. 직접 **그래스필드**를 쓸 수도 있다.
- 따라서 올리르바가 나왔다고 상대가 아무 행동도 하지 않은 상태에서 반드시 필드가 있다고 가정하지 않는다.
- 그래스필드는 일반적으로 5턴. 그라운드코트 등 연장 수단의 현실적 채용 여부는 실제 구성 확인 필요.
- 필드 발동 후 클레스퍼트라가 진입하면 **그래스시드의 방어 +1** 랭크가 생긴다.
- 필드 자체가 존재하는 시간과 **시드로 이미 얻은 방어 랭크**는 별개다. 필드 종료가 시드 상승 랭크를 자동으로 제거하지는 않는다.

### 2.2. 클레스퍼트라

- **그래스시드**: 방어 +1. 아이템이 소모된다.
- **가속**: 턴 종료에 스피드 +1(해당 턴에 실제 발동 조건 충족 시).
- **명상**: 특수공격 +1, 특수방어 +1.
- **바톤터치**: 쌓은 능력치 랭크를 실제 선택한 후속에게 전달한다. 대타출동 등도 특정 조건에서는 함께 이전될 수 있어 실전 배치 확인 대상.
- 상대의 공격에 견디고 필요한 턴을 확보해 후속을 들여보내야 하므로 **전개 단계의 행동 비용**이 중요하다.

예: 그래스시드 방어 +1, 명상 1회 특공 +1·특방 +1, 가속 2회 스피드 +2이면 **B+1 / C+1 / D+1 / S+2**를 이전할 수 있다. 이 수치는 필연적 결과가 아닌 특정 전개 성공 사례다.

### 2.3. 메가픽시

- 메가진화하면 **페어리·비행** 타입 및 **매직미러** 특성. 메가 이전 픽시와 타입/특성이 다르다.
- **비행타입이기 때문에 일반적으로 그래스필드의 회복 효과가 적용되지 않는다.** 그러나 이미 클레스퍼트라가 확보한 **방어 랭크 +1은 바톤으로 계승**할 수 있다.
- 코스믹파워는 방어 +1 및 특수방어 +1을 더해 장기전에서 공격을 견디는 조건을 강화한다.
- **어시스트파워(Stored Power)**: 위력 20 + 긍정적 능력치 상승 랭크 합계 × 20. 방어와 스피드 상승도 기술 위력에 기여하므로 방어 행동이 공격력 강화로 이어진다.
- 예: B+1/C+1/D+1/S+2를 전달받고 코스믹파워 한 번을 사용했다면 B+2/C+1/D+2/S+2, 긍정 랭크 합 7 → **어시스트파워 위력 160**. 타입 일치 보정은 없으며, 적 타입/내구 등에 따른 피해량과는 다르다.
- **매직미러**로 도발·스텔스록·일부 강제교체 변화기를 반사하여 일반적인 랭크업 저지 수단을 약화시킨다. 단 **흑안개 등 모든 대응책까지 반사하지는 못한다**. 메가진화 전후 타이밍을 별도로 검증한다.
- 필드 회복, 매직미러, 능력치 상승을 하나로 묶어 무조건적인 무적 상태라고 주장하지 않는다. 실제 사용 기술 슬롯은 회복·어시스트파워·페어리 타점·견제기·코스믹파워 등에서 선택 비용이 존재한다.

## 3. 중요한 변형별 구조적 차이

| 형태 | 핵심 능력치 공급/승리 조건 | 대응 검토의 쟁점 |
|---|---|---|
| 올리르바+클레스퍼트라+메가픽시 | 그래스시드 방어, 명상 특공/특방, 가속 스피드, 픽시 자체 코스믹파워 | 필드 시점·전달 턴·완성 후 막을 수 있는지 |
| 클레스퍼트라+메가픽시 | 명상/가속 위주. 올리르바 없이 그래스시드 발동을 자동 가정하지 않음 | 초기 물리 내구, 바톤 성공 여부 |
| 펜드라+메가픽시 | 철벽 방어와 가속 스피드의 계승 | 특공은 자동 상승이 아니며 자체 화력 확보 필요 |
| 하양허브 껍질깨기 바톤 + 수혜자 | A/C/S +2 등의 큰 상승과 도구로 방어 하락 복구 | 벽 지원, 전달자 식별 및 수혜자가 누군지 |
| 메가픽시 단독 코스믹파워 | 픽시가 직접 B/D를 축적, 어시스트파워 위력도 상승 | 바톤 차단만으로는 대응 불가 |
| 브리두라스 바톤 수령 | 전달된 랭크에 지구력·기술/내구 결합 | 픽시와는 다른 공격·수비 대응 |
| 혼합형 (예: 에써르+거북왕) | 상대가 팀 프리뷰에서 바톤 또는 별도 전개를 선택 | 6→3의 사전 선택 문제 |

**특히 무언가를 바톤으로 '어디에' 넘기느냐의 불확실성**과 메가픽시가 아예 혼자 전개하는 경우를 별도로 고려한다.

## 4. '교통사고'로 만드는 임계점

- 방어·특방·스피드가 누적될수록 통상적인 공격/스피드 역전으로 처리가 불가능해질 수 있다.
- 메가픽시의 코스믹파워는 방어 상승과 함께 어시스트파워의 위력을 높인다. 시간을 허용할수록 **상대 전개를 끊기 어려워지는 자기강화 구조**다.
- 매직미러는 일부 변화기 방해/강제교체에 대응한다.
- 따라서 **바톤을 막는 전략**, **바톤이 성공한 후 승리하는 전략**, **메가픽시 단독을 봉쇄하는 전략**을 분리하여 검증해야 한다.
- 예: **흑안개**에 의한 랭크 초기화, 직접 공격 기술인 클리어스모그 등은 매직미러와의 상호작용이 도발과 다르다. 세트의 실제 합법성과 상대의 대응 능력을 따로 확인한다.
- 강제교체·도발·랭크 삭제·스피드·급소 등 개별 대응의 실전 가능성은 상황에 따라 다르므로 '이 수단 하나면 무조건 이긴다'는 식으로 평가하지 않는다.

## 5. 이 아키타입에 대한 필수 검증 항목

1. **올리르바의 넘치는씨 발동**을 허용/회피하는 것이 실제로 우리에게 어떤 결과를 주는가? 직접 그래스필드 사용 시 전개 턴의 비용도 고려.
2. **그래스시드 방어 +1**을 발동시키고 가속·명상까지 축적할 때, 몇 턴 동안 어떤 반격이 가능한가?
3. **바톤 전달 직후** 수혜자를 공격해 처리할 수 있는가? 누구에게 전달하는지 사전에 알 수 있는가?
4. 바톤 전달을 막지 못하더라도 **어시스트파워·물리/특수 내구 상승**을 가진 최종 에이스를 이길 수 있는가?
5. 펜드라 철벽 바톤 / 하양허브 껍질깨기 바톤처럼 **서로 다른 능력치 묶음**에도 선출 계획이 성립하는가?
6. **메가픽시 단독 코스믹파워**는 바톤 방해가 통하지 않는 별도 상대임을 인정하는가?
7. 에써르·거북왕 혼합형 등 **다른 전개 코어**가 실제 출전할 때 선출 단계에서 계획이 무너지지 않는가?
8. 메가픽시의 매직미러와 메가 전 페어리 단일 타입 등 **폼 변화 타이밍**에 따른 대응이 맞는가?
9. 도발/흑안개/클리어스모그/강제교체 등 제시한 대책이 **실제로 적용 가능한 대상과 기믹**인지 확인했는가?
10. 상대 기술배치와 아이템/속도/내구의 합리적 변형에 대한 **영향도 분석**을 수행했는가?
