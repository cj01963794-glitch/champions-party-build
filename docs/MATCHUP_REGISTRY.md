# 랭커·환경 유행 파티 검토 대장

> 작성일: 2026-10-28 (KST)  
> **현재 입력 데이터: 비파티 아키타입 1건(변형군).** 구체적인 여섯 마리 세트와 아군의 검증 수순은 아직 없음.

## 관리 원칙

- 사용자 제공/합의된 대상 파티를 모두 등록하며 일부만 골라 검증하지 않는다.
- 사용자 지정 정형 전개파티를 **필수-전개**로 표시한다. 해당 항목은 상위권 사용률과 상관없이 모두 별도 필수 통과해야 한다.
- 필수군의 구조적 패배 경로 발견은 다른 대면 성능으로 상쇄할 수 없다. [필수 검증 기준](REQUIRED_SETUP_MATCHUPS.md) 참조.
- 상대 파티의 식별 ID, 버전, 출처, 등장 시기, 아군 파티 버전, 계획 상태, 검토 문서를 연결한다.
- 현재 등록된 비파티는 구체적인 6마리 개별 팀이 아닌 **변형 가능한 아키타입**이다. 세부 세트가 추가되면 하위 케이스로 분리한다. 완료된 실전 매치업 검증은 아직 없다.
- 아군 구성 변경 또는 새 기술배치 발견으로 기존 선출 플랜이 무효화되면 **재검증 필요**로 되돌린다.
- 상세한 검증 절차는 [MATCHUP_AUDIT_PROTOCOL.md](MATCHUP_AUDIT_PROTOCOL.md)를 따른다.

|---|---|---|---|---|---|---|---|---|

### 사용 상태

- **미등록:** 아직 검토 대상 데이터가 입력되지 않음.
- **미검토:** 대상 등록만 완료.
- **정보 부족:** 판단에 필요한 핵심 정보가 없음.
- **미해결:** 검토했으나 실현 가능한 대응·승리 경로를 확보하지 못함.
- **조건부 검증:** 특정 선출/배치/전제가 맞을 때만 플랜 검증됨.
- **검증 완료:** 검토 기준 충족.
- **재검증 필요:** 아군 파티 변경 또는 상대 정보 갱신으로 기존 판단의 유효성 재확인 필요.

상성 평가는 상태와 독립적으로 기록한다. 필수-전개 항목은 별도로 통과 / 실패 / 보류를 기록하며, 단순한 계획 검토 완료만으로 통과시키지 않는다.
