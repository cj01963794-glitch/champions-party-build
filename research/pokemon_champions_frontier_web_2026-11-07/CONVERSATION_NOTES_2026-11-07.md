# Pokémon Tower / Pokémon Champions Frontier — 대화 및 작업 기록

> 2026-11-07 현재 채팅에서 확인·정리한 **서술형 요약**. 대화 전체의 축자 전사가 아니다. 누가 무엇을 직접 확인했는지, 무엇이 추측인지 분리한다.

## 목적과 전제

사용자는 세계 상위권을 목표로 하는 포챔스 싱글 3v3 파티 구축을 위해 규칙 기반 전투 AI, 포챔스용 실제 배틀 엔진, 트레이너 세트와 선출 로직을 확보·검증하고자 했다. 사용자 기준에서 공격적 구축, 교체턴 피해/선공권/랭크업·선출 전체 검증, 실제 사용률 자료와 인게임 샘플 구분이 중요하다. 상대 트레이너 AI를 사용자에게 학습된 모델이라고 가정하지 않는다.

## 조사 경과(시간 순)

1. 웹사이트 `https://pokemon-tower-battle.rotatedtriangle.chatgpt.site/` 문의. 처음엔 웹 접근이 어려워 코드·원저장소를 직접 확인하지 못했다.
2. 사용자는 개발자가 AI를 머신러닝으로 학습시키지 않고 직접 규칙을 수작업으로 작성했다고 전했다. 조건 규칙 외에 시뮬레이션이 있는지는 소스를 보고 확인하기로 했다.
3. 사용자가 이 사이트가 **한국인이 2026-11-01~07에 공개한 게임**이라고 정정. 이전 대화에서 11월 4일 레쿠쟈 갤러리 게시글 `id=rayquaza&no=245573`를 관련 게시글로 찾았고, 올포타 AI 확장팩 개발 이력을 참고했다. 작성자 동일성은 최종 확정되지 않았다.
4. 7월 16일 올라온 올포타 개선 AI 관련 게시글에서 세 파일을 사용자가 전달: `pokemon_tower_updater.apk`, `pokemon_tower_updater_windows.zip`, `올라라! 포켓몬 타워!_v2_1003.zip`(Audio 폴더 제외). 가장 중요한 Ruby AI 소스는 게임 파일 안에서 찾았다. 업데이터 두 개는 AI 로직 상세 역공학을 실시하지 않았다.
5. Ruby `Battle AI Improved`의 개선 코드에서 교체, 대면 시뮬레이션, 희생 교체, 도발·트릭·흑안개 등의 평가가 식별됐다. 과거 대화에서 최대 10턴 대면·교체 후 4턴 시뮬레이션이라는 기준을 언급했다. 이 숫자는 전역 3v3 장기 수순을 자동으로 푼다는 뜻이 아니다.
6. **정정:** `v2_1003` 파일명을 10월 3일 날짜라고 잘못 해석한 적이 있다. 실제 사용자가 받은 배포글은 **7월 16일**이다. 코드 비교의 차이와 날짜 해석은 별개다.
7. 올포타 Ruby 관련 공개 저장소 `https://github.com/erablah/gouppokemontower-improved-battle-ai` 발견. 저장소 2026-02-27 생성, main 마지막 확인 커밋 2026-05-12. 커밋 공개 메타데이터의 작성자 정보와 사이트 호스트 문자열이 `rotatedtriangle`로 관련되어 보이나 동일 웹 저장소란 증거는 아니다.
8. 7월 배포본에서 추출한 개선 Ruby AI 22개, Essentials 기본 AI 11개, 호환 AI 14개 및 관련 문서/압축을 프로젝트의 `research/pokemon_tower_ai_v2_1003/`에 먼저 저장했다(별도 커밋 `359a529d9d134e28693acf133b09ce1160a6e2ee`).
9. 사용자가 크롬 개발자도구의 Network에서 HAR을 수집했다. 첫째 `이건가`: JS 중심 8요청; 둘째 `이건가2`: 초기 화면 322요청; 셋째 `이건가3`: 실제 배틀 화면 414요청. 두 번째에서 없던 `assets/workers/battle-handler.js`가 세 번째에서 확보됐다. 세 번째에 애니메이션 자산 명세도 있었지만 AI 분석 목적에서 이미지/애니메이션 자체는 불필요하기로 했다.
10. HAR에서 `assets/workers/ai-handler.js`, `observation.js`, `battle-handler.js`, `entry-selection.js`, `runtime.worker.js`, `index.js`, `battle.js` 등 실행 JS와 게임 데이터 버전 `2026-11-03.1`, 트레이너 201명(1,206 세트), 포켓몬/기술/특성/도구 데이터를 확인했다.
11. AI 자체와 관련 샘플 데이터의 보존이 목적이며 사이트 시각적 리소스의 완전 수집은 필요하지 않다는 점에 합의. 아직 웹앱의 원본 GitHub 주소는 못 찾았고, 오프라인 독립 실행·AI의 3v3 장기전 판단력·원게임과의 동일한 데미지 처리 등은 **검증하지 않은 상태**로 남긴다.
12. 이번 작업으로 민감 정보가 포함될 수 있는 **원본 HAR을 제외**하고, 브라우저가 전달한 공개 코드/게임 데이터·샘플 CSV·파일 무결성 목록과 대화 요약을 `champions-party-build`에 보존하기로 했다.

## 다음 작업자가 즉시 참고할 점

- 올포타 Ruby 코드와 Pokémon Champions Frontier 웹 JS 코드를 **서로 다른 버전·언어·출처로 구분**해야 한다.
- 웹 AI가 직접 대면 시뮬레이션과 선출 점수 평가를 한다는 정적 정보는 있다. 20턴 이상 사이클 성능·전략적 수읽기 적중률은 무조건 별도 검증해야 한다.
- 연구용으로 추출한 트레이너 표본은 웹게임 고정 상대 세트이지, M6/M7 랭크배틀 사용률 자료가 아니다.
- 새로운 코드를 프로젝트에 추가할 때 라이선스/저작권 출처, SHA-256, 확인된 함수/실행 테스트 여부를 기록한다.
