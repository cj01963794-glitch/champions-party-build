# 올포타 확장팩 AI 소스 정적 분석

대상: 사용자가 업로드한 `올라라! 포켓몬 타워!_v2_1003.zip` 내부 `Data/PluginScripts.rxdata`에서 추출한 `Battle AI Improved` 플러그인(v1.0), 22개 Ruby 파일.

## 확실히 확인한 구조

- 기초 엔진: Pokémon Essentials v21.1의 Battle::AI; 별도 개선 플러그인이 메서드를 재정의.
- 매 턴 `pbDefaultChooseEnemyCommand`는 기술들을 평가한 다음 교체/도구/희생 교체 또는 기술 선택을 수행 (`001_AI_Improved_Core.rb:363` 이후).
- `simulate_battle`은 전투 복사본에서 실제 공격/턴 종료 단계를 수행하며 기본 `max_turns`는 10 (`001b_AI_MoveSimulation.rb:282` 이후). 이 시뮬레이션은 주로 현재 대면의 특정 기술 수순을 평가함. 전체 3대3의 10턴 최적 행동을 찾는다는 뜻은 아님.
- 교체 후 평가는 `SWITCH_IN_SIM_MAX_TURNS = 4`와 진입 공격/설치기/폼 변화 시나리오를 포함 (`007_AI_Improved_ScoreReplacement.rb:25`, `:278` 이후).
- 상대 행동은 알려진 공격기 중 최고 위협의 수순을 중심으로 설정하고, 선공기/회복기 예외 로직을 두어 평가 (`001d_AI_Improved_Matchup.rb:86` 이후).
- 강화 상대(양의 랭크 합 2 이상)에서 교체를 고려하는 핸들러 (`006_AI_Improved_ShouldSwitch.rb:57` 이후).
- 희생 교체 판단에는 스피드·체력·파티 뒷자리 구분 등의 수작업 조건문이 있음 (`001g_AI_Improved_SackReplacement.rb`).
- `Fog Of War`는 상대 아이템의 일부를 미공개로 다루며, 처음 행동하기 전에 50% 확률로 상대 기술 1개를 숨김. 반대로 많은 경우 기술 대부분을 이미 참고함 (`009_Fog_Of_War.rb:1`, `:94` 이후).
- 기술 점수가 높아도 확률 가중치로 선택하므로 항상 최고 점수 행동만 선택하지 않음 (`001_AI_Improved_Core.rb:494` 이후).
- 기습 수읽기 30% 대체 공격 선택은 미리 정한 확률 규칙 (`001_AI_Improved_Core.rb:468` 이후).

## 중요한 한계

1. 해당 파일은 기존 올포타 확장팩 원본이며, 2026년 11월 공개 웹게임의 실제 코드를 획득한 것은 아님. 웹게임에 어느 부분이 그대로 이식되었는지는 불명.
2. 확인한 자료는 정적 코드 분석 결과임. 실제 게임을 실행해 테스트하거나 포챔스 공식 데미지/규칙과 전수 비교한 것은 아님.
3. 최대 10턴 시뮬레이션은 양측 파티 전체의 장기 사이클에 대해 모든 분기를 탐색하는 게임트리가 아님. 일반적으로 선택한 1:1 기술 수순을 재현하고 교체 사건에서 종료.
4. 사용자가 제외한 Audio는 AI 논리 파악에 우선순위가 낮음. Graphics는 이 분석에는 사용하지 않음.
5. 업데이터 APK/Windows ZIP은 별도 업데이터이며, 주요 AI 코드가 들어 있는 파일은 본편 `PluginScripts.rxdata`.
