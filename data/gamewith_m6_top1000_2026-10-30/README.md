# Pokémon Champions — GameWith M6 상위 구축 파티 아카이브

2026-10-30에 수집한 GameWith M6(레귤레이션 M-C) 싱글 랭크매치 상위 구축 파티 자료입니다.

- 범위: 최종 **1위 ~ 972위** 중 GameWith 원본에 기재된 **296개 파티** (1~972위 전체가 아님).
- 공개 상태: **6마리 공개 285개 / 일부 공개 2개 / 미공개 9개**.
- **626위 동순위 파티 2개**를 모두 별도 행으로 보존.
- 포켓몬 1~6은 원본에 노출된 **왼쪽부터 오른쪽 순서**이며, 선출·선봉 순서를 뜻하지 않음.
- 공개되지 않은 멤버는 **빈칸**으로 남겨 추측하지 않음.
- 목록의 메가진화 여부, 도구, 기술, 특성, 노력치는 **기본 리스트에서 단정하지 않음**.
- 이름은 정리 작업 당시의 한국어 표준화 결과를 사용하므로, 특이한 표기·인식 결과는 `original_names.csv`와 해당 PDF 페이지로 대조해야 함.

## 파일

- [parties.csv](parties.csv): 순위, 플레이어, 포켓몬 6마리, 공개 상태, 원본 PDF 파일/페이지, 출처 URL.
- [original_names.csv](original_names.csv): 같은 296개 파티의 원문 표기 대조 및 PDF 위치.
- [summary.csv](summary.csv): 원본 엑셀의 집계 및 안내 시트.

CSV는 Excel에서 한국어가 정상 표시되도록 UTF-8 BOM으로 저장했습니다.

## 원본 출처

- GameWith: https://gamewith.jp/pokemon-champions/560474
- 수집자가 직접 PDF로 보관한 `1.pdf` ~ `6.pdf`의 각 순위별 항목을 사용.
- PDF 원본 이미지는 이 폴더에 포함하지 않았으며 **표에 원본 파일명 및 해당 PDF 페이지**를 남겼습니다.
- GameWith 웹사이트는 추후 내용이 변경될 수 있습니다. 이 파일들은 2026-10-30 기준 추출 스냅샷입니다.

> 주의: 이 자료는 전체 랭크 인구나 사용률을 대표하는 무작위 표본이 아니라, 사용자 수집 PDF에서 확인 가능한 일부 상위 구축의 모음입니다. 사용 빈도 분석 시 표본 선택 편향을 감안하세요.
