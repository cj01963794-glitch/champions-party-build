# 포켓몬 챔피언즈 파티 구축 철학

포켓몬 챔피언즈에서 **강한 파티란 무엇인가**, 그리고 **어떤 기준으로 파티를 설계하고 평가할 것인가**를 지속적으로 발전시키기 위한 독립 문서 저장소입니다.

이 저장소는 기존 `champions-singles-lab`(배틀 AI / 계산기 개발)과 별개입니다. 게임 데이터나 특정 파티의 정답을 저장하는 곳이 아니라, 파티 구축에 적용할 **판단 원칙과 사고 과정**을 기록합니다.

## 운영 원칙

1. 사용자가 승인한 방향과 AI가 일방적으로 제안한 가설을 구별한다.
2. 피드백이 생기면 핵심 원칙을 수정하고, 변경 이유를 `DECISION_LOG.md`에 기록한다.
3. 기존 대화 기록은 소급해 수정하지 않는다. 현재 기준과 과거 대화가 달라질 수 있다.
4. 특정 포켓몬이나 메타의 사례를 일반 법칙으로 과도하게 확장하지 않는다.
5. 이 저장소에 있는 원칙도 무오류의 정답이 아니라, 실제 파티 검증과 사용자 피드백을 통해 개정되는 작업 기준이다.
